# Enclosure

This directory will hold the 3D-printable enclosure design once the electronics and user interaction are stable.

Planned contents:

- editable CAD/source files;
- STL/3MF exports;
- print orientation and settings;
- assembly notes;
- large button/cap design;
- speaker grille and mounting;
- USB access;
- internal standoffs for the controller and modules.

The first case should optimize **usability and iteration speed**, not cosmetic perfection.
